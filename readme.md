# TryHackMe Security Engineer Path

A collection of notes, walkthroughs, and practical exercises from the **TryHackMe Security Engineer Path**, covering core security engineering concepts, threat management, system and network security, software security, incident management, and modern web application security.

## 📚 Path Contents

### 1. Introduction to Security Engineering

Fundamentals of security engineering, security principles, defensive security concepts, and the role of security engineers in protecting systems and organizations.

### 2. Threats and Risks

Understanding cybersecurity threats, vulnerabilities, risk assessment, threat actors, attack surfaces, and methods for identifying and mitigating security risks.

### 3. Network and System Security

Exploring network and system security concepts, including secure network architecture, operating system security, access control, authentication, monitoring, and defensive techniques.

### 4. Software Security

Introduction to secure software development, common software vulnerabilities, application security principles, secure coding practices, and security testing.

### 5. Managing Incidents

Incident management and response concepts, including detection, analysis, containment, eradication, recovery, and post-incident activities.

### 6. OWASP Top 10 2025

Practical exploration of the **OWASP Top 10 (2025)** and the most significant risks affecting modern web applications, including common vulnerabilities, attack techniques, and defensive measures.
